I want you to help me start building a web application called PLAYR.

## Product idea

PLAYR is a social gaming platform where users can document their gaming journey, share what they are currently playing, and find other players with similar gaming interests.

The core idea is:

> PLAYR — Share your journey. Find your people.

Users should be able to create an account and have their own public profile page. On their profile, they can create posts/logs about games they are playing. A post can include an image, the game title, and a text where the user writes what they like, dislike, what happened during the session, progress, achievements, or general thoughts.

A big goal of the app is to help people in the gaming world connect. Many gamers feel lonely or struggle to find others to play with. PLAYR should help users discover other players based on common interests, games, platforms, language, region, playstyle, and whether they are looking for people to play with.


## Theme
  - dark theme. Gaming feeling but also like fresh and not TO nerdy. Here you can come up with some ideas for theming.

## Tech stack

I want the project to use:

- Frontend: Angular
- Backend: .NET / ASP.NET Core Web API
- Database: PostgreSQL
- ORM: Entity Framework Core
- Authentication: JWT-based authentication
- API style: REST API
- Suggested architecture: Clean Architecture or a simple layered architecture that is understandable for a solo developer
